которому спросили (схема — из `X-Forwarded-Proto` прокси при `TRUST_FORWARDED_FOR`), а ответы API и документы несут `X-Robots-Tag: noindex` (`noIndex`). Главная называется «Freenet — социальная сеть», несёт `description` и Open Graph, её заголовок — `h1`; у «о сайте», «правил» и «помощи» — свои `description`. Сайт, в отличие от API, кешируется (в нём нет ничего личного): страницу и файл по простому адресу `/static/…` браузер каждый раз сверяет с сервером (`Cache-Control: no-cache`, ответ 304, у страницы — `ETag`), а по адресу со своей версией — `/static/c/<версия>/<файл>` — файл отдаётся навсегда (`immutable`). Версия у каждого файла своя (`rest/assets.go`): дайджест его содержимого и версий файлов, которые он называет, — после деплоя браузер качает только изменившееся. Называет файл другой двумя способами, и в оба gateway подставляет версию: модуль импортирует модуль рядом с собой (`from './layout.js'` → `from '/static/c/<версия>/layout.js'` — у модуля один адрес, кто бы его ни импортировал, иначе он загрузился бы дважды), а страница, скрипт и таблица стилей называют файл целым путём одной строкой (`"/static/club.svg"`, в любых кавычках). Поэтому изменившийся файл меняет версию и тех, кто его называет, по цепочке; модули, импортирующие друг друга по кругу (`posts.js` ↔ `share.js`), делят одну версию (сильно связные компоненты, `circles`). Файлы читаются в память и перечитываются, когда изменились их имена, размеры или времена (проверка — не чаще раза в секунду): сохранённый при разработке файл отдаётся сразу. Файл по адресу с чужой версией и по адресу прежних сборок `/static/v/<версия сайта>/…` (страница, открытая до деплоя) отдаётся с `no-cache`. Перед скриптом страницы (`<script type="module">`) gateway перечисляет `<link rel="modulepreload">` всех модулей, которые он импортирует на любой глубине (`preloading` в `rest/pages.go`, импорты файла — `staticFile.imports`): браузер просит их все разом, а не узнаёт о каждом от предыдущего. Поэтому путь к файлу в HTML и в скрипте — только целиком, `"/static/…"` одной строкой, без склейки и шаблонов: иначе он останется простым адресом без версии. `TestAssets_Website` проверяет это на самом сайте. Новые пути страниц добавлять в зарезервированные никнеймы (`user/internal/user/nickname.go`).
- Ссылка «назад» в шапке (и стрелка в шапке телефона) ведёт не к прошлому действию, а к прошлому разделу Freenet: `layout.js` ведёт в `sessionStorage` (`freenet.trail`, до 30 адресов) след страниц вкладки — по одному на раздел (адрес без запроса), так что смена вкладок и страниц внутри раздела назад не возвращает, а «назад» уходит в предыдущий раздел; без хранилища остаётся кнопка браузера.
- После действия внизу страницы она не обновляется целиком и не прыгает наверх: скрипт перерисовывает только изменившийся блок через `replaceInPlace` (`layout.js`: блок держит свою высоту, пока новое содержимое не разложено, и прокрутка остаётся на месте), а итог действия, если его надпись вне экрана, дублирует `notify` (`modal.js`) всплывающим `toast`. Новые действия перерисовывают свой блок так же, а не всю страницу.

`calls.js` — звонки между двумя людьми (`docs/features/messages.md`, «Звонки»): окно поверх страницы `.call-*` в `style.css` и `m.css` (на телефоне — во весь экран), иконки `static/icons/call-*.svg`. `layout.js` подключает его через `import('/static/calls.js')`: только целый путь даёт модулю тот же адрес, что и статический импорт в `dialog.js`, а относительный `import()` загрузил бы вторую копию со своим состоянием (проверяет `syntax.test.js`).
