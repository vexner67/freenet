# Федерация (Fediverse, ActivityPub)

Вынесено из §1 AGENTS.md: как устроена эта функция. Правила разработки — в AGENTS.md; отличия и долги — в `docs/deviations.md`.

В openvk федерации нет; сделана по просьбе владельца (2026-11-02), первая часть — только «наружу». Человек открывает свою страницу для Fediverse (Mastodon, Pleroma, Misskey и другие серверы ActivityPub): там её находят по адресу `@никнейм@домен`, читают и подписываются на неё, а записи его стены приходят подписчикам. Чужие записи, лайки и комментарии из Fediverse пока не принимаются.

**Сервис `federation`** (порт 7058, метрики 9058, своя БД) — единственный, кто говорит на ActivityPub. Домен `internal/fedi`: `Site` — адреса объектов от `PUBLIC_URL` (актор `/ap/users/<ID пользователя>`, ключ `#main-key`, входящие `/ap/users/<ID>/inbox` и общие `/ap/inbox`, подписчики и outbox, заметка `/ap/posts/<ID записи>`); актор назван по ID, а не по никнейму, который меняется. `Account` — открыта ли страница и её пара ключей RSA-2048 (создаётся при первом открытии; закрытая страница остаётся записью с `open=false`, чтобы подписать последнее `Delete`). `Follower` — актор другого сервера и куда ему доставлять (общий inbox его сервера, если он на том же хосте). `Remote` — кешированный актор другого сервера (inbox, ключ), не старше суток; его `id`, inbox и ключ обязаны быть на хосте, откуда документ получен. `Post.Federates` — какие записи уходят: только свои записи на своей стене (не на чужой и не от имени группы), не репост, не платная, не в архиве. Текст записи становится HTML `TextHTML`: экранирование, абзацы и `<br>`, ссылки `http(s)://` и обращения `[ник|Имя]` — ссылки на страницы; фото — вложения `Image` с адресом `/media/photos/…/large.jpg`, NSFW — `sensitive`.

**Чтение.** Gateway отдаёт публично: `GET /.well-known/webfinger?resource=acct:ник@домен` (JRD), `GET /ap/users/{id}` (Person с `publicKey`, `endpoints.sharedInbox`, фото), `/followers` (только число), `/outbox` (пустой — записи приходят подписчикам сами), `GET /ap/posts/{id}` (Note). Браузер, который просит HTML (ссылка на актора или заметку из Mastodon), уходит 302 на саму страницу или запись. Закрытая для Fediverse, скрытая (видна в интернете не всем) или удалённая страница и неуходящая запись — 404. Страницу и запись `federation` берёт у `user` (`GetProfiles` — никнейм, затем `GetProfile` как гость) и `post` (`GetPost` как гость) — то есть видит то же, что гость сайта.

**Входящие.** `POST /ap/inbox` и `/ap/users/{id}/inbox`: gateway передаёт запрос как пришёл (метод, путь, заголовки в нижнем регистре с `host`, тело до 256 КБ) во внутренний `Receive` (только для mTLS-идентичности `gateway`), отвечает 202. `federation` проверяет HTTP Signature (draft-cavage, `rsa-sha256`; подписаны `(request-target)`, `host`, `date` и `digest`, если есть тело; `Date` — не дальше 12 часов) ключом актора из `keyId`, перечитав актора один раз, если подпись не сошлась (ключ сменился). Актор запроса должен совпадать с владельцем ключа. Принимаются `Follow` (сохраняет подписчика и в той же транзакции отправляет ему `Accept`), `Undo` `Follow` и `Delete` самого актора (забывает его подписки); остальное — 202 без действия. Частота — не больше 600 действий в минуту с одного хоста (в памяти реплики), сверх — 429.

**Исходящие.** `post` сообщает о своих записях внутренним `PostChanged` (только для `post`) через свой outbox (поток `federation`, ключ — ID записи; `post/internal/fediclient`, `FEDERATION_SERVICE_ADDR`; без адреса — ничего): публикация (и отложенной записи), правка и удаление записи на своей стене — в транзакции изменения. `federation` превращает их в `Create`/`Update` с Note или `Delete` с `Tombstone` и раскладывает по общим inbox-ам подписчиков (каждый сервер — один раз). Закрытие страницы (`DELETE /api/v1/me/federation`) шлёт `Delete` актора всем подписчикам и забывает их. Доставка — свой outbox `federation` (поток `deliveries`, `outbox.Keyed` по хосту inbox-а: медленный сервер не держит другие): запись `{inbox, signer, body}` подписывается ключом страницы при отправке, повторы с нарастающей паузой до `DELIVERY_MAX_AGE` (48 ч); отказ 4xx (кроме 408 и 429) и закрытая/удалённая страница — запись отбрасывается. Чужие серверы `federation` спрашивает только по https на порт 443 и только публичные адреса — проверка после DNS в `Dialer.Control` (`internal/remote`), до 3 перенаправлений, `REMOTE_TIMEOUT` (10 с), ответ до 1 МБ.

**Настройка.** `GET/PUT/DELETE /api/v1/me/federation` → `{open, followers, domain}`; открыть можно только страницу, которую в интернете видят все (иначе 409). На сайте — блок «Fediverse» внизу вкладки «Приватность» настроек (`showFediverse` в `settings.js`): состояние, адрес `@ник@домен` и число подписчиков в других сетях с «?», кнопка «Открыть страницу для Fediverse» / «Закрыть страницу для Fediverse» (закрытие — с окном подтверждения). Без `FEDERATION_SERVICE_ADDR` у gateway маршрутов нет (404), и блок не показывается. Никнейм `ap` зарезервирован.

**Прод.** `PUBLIC_URL` — `https://${SITE_ADDRESS}` (`deploy/compose.prod.yaml`): адреса в Fediverse зависят от домена, менять его — значит потерять подписчиков. Переменные БД `FEDERATION_POSTGRES_*` `deploy/deploy.sh` дописывает в `.env` сервера сам.
